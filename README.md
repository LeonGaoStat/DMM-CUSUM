# DMM-CUSUM

Simulation and localization code accompanying the manuscript:

**From Alarm to Attribution: Monitoring and Diagnosis of Dynamic Count Networks via Degree-Corrected Mixed Membership**

Xiaolei Gao, Chunjie Wu, Miaomiao Yu, and Fugee Tsung.

This repository contains the proposed method's simulation and localization/diagnostic workflows. Empirical-analysis code and the original passenger-flow data are not included in this repository. Synthetic simulation data are generated by the code; saved calibration inputs needed for membership-shift experiments are included.

## Repository contents

```text
code/
  run_proposed.py                 # IC, OC and optional robustness workflows
  run_table5_proposed.py          # Localization and type diagnosis
  proposed_workflow_commands.json # Experiment parameters and commands
  requirements-current-mac.txt    # Simulation environment
  simulation/                    # Generators, methods and calibration inputs
  localization/                  # Localization workflow and dependencies
  README.md                      # Detailed Chinese instructions
```

Paper table numbers below follow the current manuscript. Some original implementation filenames use earlier table numbers.

## Environment

The simulation workflows use Python 3.12.2, NumPy 1.26.4, SciPy 1.13.1, pandas 2.2.2, and Numba 0.59.1. The localization workflow uses Python 3.9.6, NumPy 2.0.2, SciPy 1.13.1, and pandas 2.3.3. Dependency lists are provided in `code/requirements-current-mac.txt` and `code/localization/requirements.txt`. Use separate environments for these two workflows.

## Running the simulations

From the repository root, enter the code directory:

```bash
cd code
python run_proposed.py --help
python run_proposed.py --list
```

To execute the IC, activity-shift OC, and membership-shift OC workflows:

```bash
python run_proposed.py --execute
```

To also run the supplementary robustness experiment:

```bash
python run_proposed.py --execute --include-robustness
```

Core results are written to `rerun_proposed/core/`; the workflow including robustness writes to `rerun_proposed/with_robustness/`. Use `--resume` with the same configuration to resume an existing run. With no arguments or with `--list`, the launcher only displays instructions or the workflow list.

Membership-shift experiments read the saved control-limit CSVs under `simulation/Table6_membership_shift_final/calibration/`. Complete experiment commands and parameters are recorded in `proposed_workflow_commands.json`.

## Running localization and type diagnosis

In the localization Python environment, from `code/`:

```bash
python run_table5_proposed.py --help
python run_table5_proposed.py --execute --out localization/results_proposed_01
```

This entry point runs the fixed paper scenarios.

## Outputs and approximate runtimes

Times below are approximate on an Apple M3 computer with 8 CPU cores and 8 GB RAM running macOS 15.5. Membership-shift and robustness times are estimates.

| Manuscript output | Entry point | Approximate time |

| Main Table 3: activity-shift OC ARLs and standard errors | `run_proposed.py` | 1 hour |
| Main Table 4: membership-shift OC ARLs and standard errors | `run_proposed.py` | 40 minutes (estimate) |

These entries concern the proposed method. Shared original modules retain their supporting functions; use the entry points above for the supplied workflows. Source and input manifests inside `code/` record the packaged versions.
